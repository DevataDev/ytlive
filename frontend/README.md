# YT Live Dashboard - Frontend

This is the Next.js frontend for the YT Live Dashboard application.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `/src/app` - Next.js app directory with pages and API routes
  - `/dashboard` - Dashboard page
  - `/stream-list` - Stream listing page
  - `/api` - API routes
- `/src/components` - Reusable React components
  - `/layout` - Layout components (Header, Footer, etc.)
- `/public` - Static files

## Features

- Modern React with TypeScript
- Bootstrap 5 for responsive design
- Client-side data fetching
- API routes for backend communication

## Development

- Use `npm run dev` to start the development server
- Use `npm run build` to create a production build
- Use `npm start` to start the production server

## Deployment

To deploy, build the application and serve the static files using a static file server or deploy to a platform like Vercel or Netlify.
